# News Search (Raycast)

Mirror of the BTT `NewsSearchPlugin` for Raycast: type a query, get the latest articles from Google News RSS with source logos and quick-open actions.

## Features

- Live search-as-you-type against Google News RSS (debounced)
- Per-article source logos (Clearbit primary, Google favicon fallback)
- Relative "X ago" timestamps
- Region/language switcher in preferences (US, UK, IN, CA, AU, DE, FR, JP)
- Actions: Open in Browser (↵), Copy URL (⌘C), Copy Title (⌘⇧C), Copy Markdown Link (⌘⇧M)

## Preferences

- **Region & Language** — Google News locale (default US English)
- **Max Results** — 1–50, default 25
- **Show Thumbnails** — toggle source logos on/off
